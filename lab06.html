Oceanside Hometown Map

My Oceanside

This interactive map showcases the locations I feel are the most important places in Oceanside, California - my beautiful coastal hometown in San Diego, California. Click on any marker to see details about the location, including a personal description and a photo. The map uses a custom Mapbox style and is color-coded by location type for easy navigation.

Reflection

I chose an image of a sunset beach for the color scheme inspiration for my map. Most of my favorite moments in Oceanside have been at sunset, so I wanted to base the map on that aesthetic. I chose pink as the terrain color because when you zoom out, it looks like the pink clouds in the image. I selected yellow and orange tones for the rest of the land so that when you zoom in, it becomes more of a blue and orange sunset. The zoom function was challenging because I had to adjust colors at different zoom levels to maintain the sunset look at all levels. The final map was created using Python, the Folium library, and Mapbox's Geocoding. I started by collecting data on 16 meaningful locations across Oceanside, organizing them in a CSV file with addresses, descriptions, and image URLs. Using AI, I wrote Python code to automatically geocode each address and plot them on the interactive map with my custom Mapbox basemap style. One technical challenge was ensuring accurate marker placement. Some locations required manual coordinate corrections to appear where they really are on the map. I customized each marker with different colors and icons based on location type, and each marker includes an interactive pop-up featuring the location name, my description, and a photo. I used Claude Sonnet 4.5 to develop both the Python mapping code and this Lab 6 portfolio page. AI assistance was invaluable in this project because I had never created an interactive map before and had no idea where to start. Through this process, I learned how to integrate multiple technologies and create something with a cohesive aesthetic and personal meaning.
