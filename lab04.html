Reflection & Analysis

Data Preparation

The only error I experienced while preparing and uploading my data was that the data was in XLSX format, which isn't compatible with Tableau. I just had to save the data as a CSV file, and then it worked perfectly. I downloaded data from Kaggle that was in perfect shape for this type of project, so I didn’t need to scrape or clean any data beforehand.

Design Choices

When creating these visualizations, there was a learning curve. This was the first time I have used Tableau, and I needed to learn how to use the program while learning how to discern what data is important to include and how to represent it. I chose to use the data on brand equity and represented it in a bar graph and a map. Both of these visualizations show the same data but in a completely different way. The map shows the equity in the industry based on location, which could be helpful to see the geographic spread of the industry, while the bar graph is more focused on growth over time for each brand. Each brand’s data is presented alongside the others, so it is easy to compare patterns and draw conclusions. I chose to use colorful markers to make them more interesting and make the data easily readable. I also included the keys to make the importance of the data clear.

Expected Patterns & Surprises

While there is some missing data, and I don’t think the numbers are accurate or actually applicable, there are still noticeable trends and patterns in the data that could mimic actual fashion industry data. As mentioned, both visualizations analyze different aspects of brand equity across a time period. When thinking about the geographic spread of the industry, I definitely expected there to be more equity - a darker green dot - in places like Italy and France because there are so many brands with such an impact from those countries. However, according to this data, there was the most equity in the United States, which could be true because there is so much consumer power in the US that can attribute equity to the US brands. The visualization that was focused on growth over time had more obvious issues, like years of missing data, but I was still able to observe some patterns, like a strong and steady growth in brands like Hermes and Nike.

Questions for Further Investigation

There could be deeper questions for further evaluation, like “Why is there more equity in American brands?” or “How can we collect data for the missing years in order to get a more complete picture of the companies’ equity?”

Tool Evaluation

Tableau is a very useful tool that can help create in-depth visualizations. It can help the user to create something with meaning by suggesting what kind of graph to use and producing advanced representations like a map. However, I did experience a lot of limitations, such as not being able to manipulate the data as I was creating the visualizations, such as getting the sum of a category. These are functions I have grown accustomed to because of Excel.
